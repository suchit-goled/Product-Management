Suchit Developer API Reference

RESTful API endpoints available in the Suchit Catalog Engine for integrations

POST /upload

Upload a product image. Form fields: image (binary), save_immediately ('true'|'false'), model.

GET /products

Fetch all catalog products. Optional query parameters: ?search=...&category=...&brand=...&sort=...

GET /product/<id>

Retrieve a single product by ID as a structured JSON object.

PUT /product/<id>

Update fields for product by ID with JSON body.

DELETE /product/<id>

Delete product from database by ID.

GET /export/pdf/<id> • /export/pdf

Download single-product or full catalog PDF specification book.
